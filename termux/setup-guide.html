How the Friend Gets the URL

Every time you start the server, the public URL is automatically sent to your friend via a Telegram bot. Your friend opens Telegram, taps the link, types it in their Xiaomi TV MI Browser — done. No manual copy-paste. No calling each other. It just works.

2

Create a Telegram Bot (1 minute)

So the URL gets auto-sent to your friend

v
A

Open Telegram on your phone

Search for @BotFather and tap START

B

Send: /newbot

Give it any name like MyJioTVBot

C

Copy the Bot Token

Looks like: 7123456789:AAFxxxxxxxxxxxxxxxxxxxx

D

Your friend opens @userinfobot

Send /start — it replies with their Chat ID (a number). Share that with you.

Note: Your friend must also START your new bot (search by bot username in Telegram and tap Start) before they can receive messages.
3

Copy JioTv Files to Your Phone

Place in /sdcard/JioTv/

v

Transfer the JioTv project folder to your phone via USB or Google Drive and place it at:

/sdcard/JioTv/
4

Run One-Command Setup in Termux

Installs everything + asks for your Telegram bot token

v

First, allow storage access:

termux-setup-storage

Then run the full setup:

curl -sL https://raw.githubusercontent.com/Jitendraunatti/JioTv/main/termux/setup.sh | bash
During setup it will ask for:
+ Telegram Bot Token (from @BotFather)
+ Friend's Telegram Chat ID (from @userinfobot)
It will verify and send a test message to your friend instantly.
5

Start JioTV Server

URL auto-sent to friend on Telegram every time

v 
~/start-jiotv.sh
What happens automatically:
1. PHP server starts on your phone
2. Cloudflare creates a public HTTPS URL
3. URL is sent to your friend's Telegram
4. A QR code is shown in Termux
5. Phone notification with the URL appears
6

Keep Your Phone Running 24/7

Charger + wakelock = always online

v
  • + Keep phone plugged into charger
  • + Settings > Battery > Disable battery optimization for Termux
  • + Script runs termux-wake-lock automatically
  • + Termux:Boot auto-restarts server if phone reboots
  • + If URL changes, friend gets a new Telegram message automatically
